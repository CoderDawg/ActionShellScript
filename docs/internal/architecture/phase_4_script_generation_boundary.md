# Phase 4 Script-Generation Boundary

Phase 4 turns a `ShapedActionSequence` into a derived `GeneratedScript`.

Its job is intentionally narrow:

- consume shaping output without mutating it
- render stable script text for preview and export
- keep generated script clearly non-authoritative

Phase 4 does not create editable script authority. That transfer still belongs to phase 5, where `GeneratedScript` is converted into a `ScriptDocument`.

## Source Of Truth

- `ShapedActionSequence` is the authoritative recording-derived representation for phase 4.
- `GeneratedScript` is rebuildable output.
- Regenerating script text must not mutate `ShapedActionSequence.actions`.
- Generated text can be discarded and rebuilt from shaping truth.

## Target Output Contract

Phase-4 output is executable ASS function-call text for the shaped action vocabulary this phase supports.

The current contract is:

- Header comments are optional and start with `#`.
- When enabled, the header begins with `# Generated by ActionShellScript`.
- When source summary comments are enabled, the header also includes source session id and shaped action count.
- Generated non-empty scripts always end with exactly one configured line ending.
- Empty generated scripts produce an empty string.

## Action Rendering Contract

- `delay` renders as `Sleep(duration_ms)` when generation delay emission is enabled.
- `hotkey` renders as `Hotkey("ctrl", "c")` style calls using the shaped key order.
- `hotkey` may also derive its rendered order from shaped `modifiers` plus `trigger_key` when `keys` is absent.
- `key_down` renders as `KeyDown("key")`.
- `key_up` renders as `KeyUp("key")`.
- `key_hold` renders as an explicit `KeyDown`, optional `Sleep(duration_ms)`, then `KeyUp`.
- `mouse_click` renders as `MouseClick("button", x, y, clicks)`.
- `mouse_down` renders as `MouseDown("button", x, y)`.
- `mouse_up` renders as `MouseUp("button", x, y)`.
- `mouse_move` renders as `MouseMove(x, y)`.
- `mouse_drag` renders as an explicit `MouseMove(start)`, `MouseDown`, optional `Sleep(duration_ms)`, `MouseMove(end)`, `MouseUp` sequence.
- `mouse_wheel` renders as `MouseWheel(delta)`.
- `text` renders as `SendText("text")`.

`key_hold` and `mouse_drag` intentionally keep their own embedded timing even when standalone `delay` actions are omitted from generation output. That timing is part of the action’s meaning, not an optional inter-action pause.

## Unsupported Actions

- Supported shaped action types should render intentionally, not silently disappear.
- If a known shaped action is missing required contract fields for rendering, generation emits `# Unsupported shaped action: ...` instead of silently dropping it.
- Unknown non-contract action types are omitted by default.
- When `emit_metadata_comments` is enabled, unknown non-contract action types render as `# Unknown action: ...` comments.

## CLI Vertical Slice

Phase 4 is exposed through `ass-generate`.

The command:

1. loads a saved raw session JSON file
2. interprets it
3. shapes it
4. generates `GeneratedScript.text`
5. prints the generated script preview and can optionally write it to disk

That path proves phase 4 as a real end-to-end slice rather than a disconnected renderer module.
