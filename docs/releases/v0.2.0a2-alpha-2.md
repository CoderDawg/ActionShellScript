## User-Visible Changes

- Added configurable workspace tab attention highlighting so the desktop window can draw focus to the tabs you care about.
- Updated the help launcher and help browser to use the frog icon, and kept help-browser selection state in sync when a document is missing.
- Fixed a Pixel Inspector teardown crash that could happen while coordinate capture was active.
- Renamed the editing save-time section in Preferences to `Save` for clearer navigation.
- Removed public architecture references from the help docs so the built-in help now stays focused on user-facing guidance.

## Packaging And Release

- Trimmed the PyInstaller Qt bundles and installer payload to reduce release bloat.
- Fixed the `ass-cli` installer shortcut and related packaging behavior.
- Added a packaging-notes-only switch for release workflows and documented the PyInstaller fallback path.
- Cleaned up release-stage help smoke-test teardown and release-path reporting.

## Documentation Updates

- Added phase 7 debugger boundary documentation under the internal architecture tree.
- Moved internal architecture content out of the public help surface.
- Updated packaging release notes so the current release token is documented consistently across the repo.
